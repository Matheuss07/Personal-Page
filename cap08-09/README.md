# Projeto CSS Zen Garden

## Autor
Matheus dos Santos Luna

## Tema
Hacker Interface Minimalista

## Design de Referência
Mid Century Modern

## Link de Referência
https://www.csszengarden.com/221/

## Descrição
O projeto foi desenvolvido utilizando CSS Grid para a estrutura principal da página e Flexbox para organização dos componentes internos.

A proposta visual foi inspirada em interfaces utilizadas em sistemas Linux, terminais de programação e ambientes de desenvolvimento voltados para tecnologia e segurança da informação.

## Recursos Utilizados
- CSS Grid
- Flexbox
- Variáveis CSS
- Media Queries
- Responsividade
- Layout inspirado em interfaces de terminal
