3. Glossário Técnico

HTML
Linguagem de marcação usada para estruturar páginas web.
CSS
Linguagem responsável pela estilização visual.
JavaScript
Linguagem de programação para interatividade.
DOM
Modelo de objetos que representa elementos HTML.
API
Interface de comunicação entre sistemas.
Conjunto de regras para integração de software.
HTTP
Protocolo de transferência de dados na web.
URL
Endereço Web
Localização de um recurso na internet.
DNS
Sistema de Nomes de Domínio
Traduz nomes de domínio para endereços IP.
