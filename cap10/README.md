# Projeto — Recriação Responsiva

## Autor
Matheus dos Santos Luna

## Site Escolhido
Cisco Networking Academy (NetAcad)

## Link do Site
https://www.netacad.com/pt

## Objetivo
Criar uma homepage responsiva inspirada visualmente na Cisco Networking Academy, usando apenas HTML5 e CSS3.

## Estratégia Responsiva
O projeto usa a estratégia Mobile First. Primeiro foi criado o layout para celulares, com os elementos em coluna. Depois foram adicionadas media queries para adaptar o conteúdo em telas maiores.

## Breakpoints
- 768px
- 1024px
- 1440px

## Recursos Utilizados
- HTML5
- CSS3
- Flexbox
- CSS Grid
- clamp()
- Variáveis CSS com `:root`
- Media Queries
- `prefers-color-scheme`
- Imagens responsivas

## Adaptações Realizadas
Foi criada uma marca fictícia chamada NetLab Academy. A página mantém uma aparência educacional e tecnológica, usando cores próximas ao azul corporativo, seções de cursos, cards informativos, estatísticas, benefícios e chamada para matrícula.

A estrutura foi simplificada. O CSS usa poucas classes, nomes simples e regras fáceis de explicar.

## Dificuldades
A principal dificuldade foi deixar a página responsiva sem usar Tailwind ou JavaScript.

Também foi necessário organizar os cards com CSS Grid e o cabeçalho e o hero com Flexbox, mantendo o código simples e compreensível.
